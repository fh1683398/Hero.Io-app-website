# App Store Web Application

A responsive App Store style web application built with React and Vite.

It allows users to browse apps, search, view details, and manage installations using localStorage.

---

## Features

- Responsive design for all devices
- Live search functionality
- App details with rating chart
- Install / uninstall system
- Sorting by downloads
- Custom 404 page

---

## Tech Stack

- React
- Vite
- React Router
- Recharts
- LocalStorage API
- CSS / Tailwind
